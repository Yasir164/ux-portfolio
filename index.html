01

MindBridge

Mental health peer support for everyone — a free, anonymous mobile app and responsive website bridging the gap between generic wellness apps and expensive clinical platforms.

Mobile App Responsive Web Mental Health Safety-First UX
18 ScreensFully linked hi-fi 5 PersonasResearch-driven FigmaiOS + 3 web breakpoints
Click to read case study
↗

The Problem

Mental health tools occupy two extremes — expensive clinical platforms ($65+/week) and generic wellness apps with no human connection. People in the pre-clinical range, caregivers, and users from high-stigma cultures fall through the gap entirely.

Competitive audit: 5 rivals (Calm, Headspace, BetterHelp, 7 Cups, Woebot). No competitor combines peer community, mood tracking, and crisis support in one free anonymous product.

Key Decisions

  • Anonymous-first identity — username before any account. Email is recovery-only, never shown to others.
  • Crisis support in persistent nav — not buried in settings. 0/5 users found it when hidden; now present on every screen.
  • No streaks or gamification — designed for non-daily use. Guilt-free for caregivers with unpredictable schedules.
  • Sage Calm palette — purple-violet warmth over clinical white. All 5 testers praised it unprompted.

Usability Testing Results

P0 Critical

Peer circle invisible. 0/5 found it unaided. P3: "It just looks like a meditation app." Redesign home screen to lead with circles.

P0 Critical

Anonymous not trusted. 4/5 expressed distrust. P4: "It says anonymous but asks for email." Fix: optional recovery field + privacy preview.

P0 Critical

Crisis pathway buried. 0/5 found it. Was 3 taps deep in Settings. Now persistent nav element.

Strength

Visual palette praised by all 5. P2: "A safe space before I've read anything."

02

Pocket

Personal finance & budgeting for everyone. An adaptive app with an income-mode selector that restructures the entire experience for students, freelancers, couples, and retirees.

Mobile App Responsive Web FinTech Data Visualisation
16 ScreensFully linked hi-fi 5 User TypesAdaptive onboarding FigmaiOS + responsive web
Click to read case study
↗

The Problem

Every budgeting app assumes a salaried adult with stable monthly income. Students on allowances, freelancers with variable income, couples needing shared visibility, and retirees on fixed pensions are structurally underserved.

Competitive audit: Mint, YNAB, Money Manager, Spendee, Google Sheets. No competitor supports variable income as a core feature. Shared budgeting is paywalled everywhere.

Key Decisions

  • Income mode selector — Salary / Allowance / Freelance / Pension. One choice restructures budgets, alerts, and projections. Most differentiated feature in the market.
  • Chart-first dashboard — donut chart leads. P1: "I can see I spent too much on food just from the chart."
  • Two-tap expense entry — amount + category only. Core interaction minimised.
  • Free shared budget — couples get joint visibility without merging accounts. YNAB and Spendee both paywall this.

Usability Testing Results

P0 Critical

Income mode labels misunderstood. 3/5 confused — 2 abandoned onboarding. P3 chose Salary as a student because it felt "safe." Fix: plain-English descriptions + "you can change this later."

P0 Critical

Add expense button invisible. 5/5 missed the FAB. P4 scrolled looking for "add." Fix: sticky labelled button above nav bar.

Strength

Income mode concept resonated strongly once understood. P4: "This is why every other app doesn't work for me." Chart-first dashboard praised by 4/5.

03

SchoolRoute

Bus schedule tracking and carpool management for parents and students. A dark-themed iOS app consolidating real-time tracking, carpool discovery, and smart notifications.

Mobile App iOS Transport Real-time UX
15 ScreensFully linked hi-fi 2 User RolesParent & Student FigmaiOS Mobile
Click to read case study
↗

The Problem

School transport coordination is fragmented across WhatsApp groups, paper timetables, and newsletters. Parents have no real-time bus visibility and no way to safely discover carpools. Safety and real-time clarity ranked higher than any other need in user research.

Personas: Aisha Khan (38, working mother, Kaohsiung) — needs verified safety. Daniel Chen (17, basketball player, Taichung) — needs flexible carpool options outside bus hours.

Key Decisions

  • Dark theme + colour-coded cards — technical feel for real-time transport. Layered near-black system creates depth without gradients.
  • Role-based onboarding — Parent vs. Student set once at setup. Parents see verification; students see flexibility.
  • Dot-and-line route tracker — familiar transit pattern. P4: "This is like Moovit but for school."
  • Clean minimal density — time-pressured users need fast scanning, not complexity.

Usability Testing Results

P0 Critical

Carpool safety blocked task completion. 3/5 parents hesitated or abandoned. P1: "Is this school-verified?" Fix: verified parent badge + visibility tooltip.

P0 Critical

Carpool feature undiscoverable. 2/3 parents couldn't find it via nav. P1 tapped Routes. Fix: "Find a Carpool" shortcut on home dashboard.

Strength

P5: "I like that it is not cluttered." Clean minimal design reduces cognitive load for time-pressured parents. Preserve across iterations.
